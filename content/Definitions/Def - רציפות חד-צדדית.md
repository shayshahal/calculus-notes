# הגדרה: רציפות חד-צדדית

## רציפות מימין

פונקציה $f : [a,b] \to \mathbb{R}$ נקראת **רציפה מימין** בנקודה $a$ אם:
$$\lim_{x \to a^+} f(x) = f(a)$$

## רציפות משמאל

פונקציה $f : [a,b] \to \mathbb{R}$ נקראת **רציפה משמאל** בנקודה $b$ אם:
$$\lim_{x \to b^-} f(x) = f(b)$$

## הגדרה לפי קושי

אפשר להגדיר רציפות חד-צדדית בעזרת קושי באופן דומה:

**רציפות מימין ב-$a$:**
$$\forall \epsilon > 0 \; \exists \delta > 0 : a \leq x < a + \delta \Rightarrow |f(x) - f(a)| < \epsilon$$

**רציפות משמאל ב-$b$:**
$$\forall \epsilon > 0 \; \exists \delta > 0 : b - \delta < x \leq b \Rightarrow |f(x) - f(b)| < \epsilon$$

## הסבר

- רציפות חד-צדדית חשובה בקצוות של קטע סגור
- פונקציה רציפה בנקודה פנימית אם ורק אם היא רציפה משני הצדדים
