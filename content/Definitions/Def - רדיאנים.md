# הגדרה: רדיאנים

## הגדרה פורמלית

**רדיאן** הוא יחידת מדידה לזווית. היקף מעגל היחידה (מעגל ברדיוס 1) הוא $2\pi$, ולכן:

- $2\pi$ רדיאנים = $360°$ (הקפה מלאה סביב המעגל)
- $\pi$ רדיאנים = $180°$ (חצי מעגל)

## הסבר

רדיאנים מודדים זווית על פי אורך הקשת במעגל היחידה. זווית של רדיאן אחד היא הזווית שיוצרת קשת באורך 1 על מעגל היחידה.

## המרות נפוצות

| רדיאנים | מעלות |
|---------|-------|
| $0$ | $0°$ |
| $\frac{\pi}{6}$ | $30°$ |
| $\frac{\pi}{4}$ | $45°$ |
| $\frac{\pi}{3}$ | $60°$ |
| $\frac{\pi}{2}$ | $90°$ |
| $\pi$ | $180°$ |
| $2\pi$ | $360°$ |
