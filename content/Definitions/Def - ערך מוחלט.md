# הגדרה: ערך מוחלט

## הגדרה פורמלית

יהי $x \in \mathbb{R}$. נגדיר את **הערך המוחלט** של $x$ להיות:

$$|x| = \begin{cases}
x & x \geq 0 \\
-x & x < 0
\end{cases}$$

## תכונות בסיסיות

1. $|x| \geq 0$ לכל $x \in \mathbb{R}$
2. $|x| = 0 \iff x = 0$
3. $|-x| = |x|$
4. $|xy| = |x| \cdot |y|$

## תכונה חשובה

$$|x| \leq a \iff -a \leq x \leq a$$

(עבור $a \geq 0$)

## תכונה נוספת

$$|x| \geq a \iff (x \geq a \text{ או } x \leq -a)$$

(עבור $a \in \mathbb{R}$)
