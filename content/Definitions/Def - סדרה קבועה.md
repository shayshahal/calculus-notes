# הגדרה: סדרה קבועה

## הגדרה פורמלית

סדרה $(a_n)$ נקראת **סדרה קבועה** אם קיים $c \in \mathbb{R}$ כך שלכל $n \in \mathbb{N}$:

$$a_n = c$$

## הסבר

סדרה קבועה היא סדרה שכל איבריה שווים לאותו מספר.

## התכנסות

סדרה קבועה $a_n = c$ מתכנסת לגבול $c$:

$$\lim_{n \to \infty} a_n = c$$

**הוכחה:** לכל $\varepsilon > 0$, נבחר $N = 1$. אז לכל $n \geq N$ מתקיים:
$$|a_n - c| = |c - c| = 0 < \varepsilon$$

## דוגמאות

1. $a_n = 5$ לכל $n$ היא סדרה קבועה

2. $a_n = 0$ היא הסדרה הקבועה אפס

3. $a_n = \pi$ היא סדרה קבועה
