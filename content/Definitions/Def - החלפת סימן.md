# החלפת סימן

הגדרה של פונקציה המחליפה סימן בנקודה.

## הגדרה

נניח $f$ מוגדרת בסביבה מנוקבת של הנקודה $x_0$.

נאמר כי $f$ **מחליפה סימן ממינוס לפלוס** ב־$x_0$ אם קיים $\delta > 0$ כך ש:

$$f(x) < 0 \quad \forall x_0 - \delta < x < x_0$$
$$f(x) > 0 \quad \forall x_0 < x < x_0 + \delta$$

## החלפה מפלוס למינוס

באופן דומה, $f$ **מחליפה סימן מפלוס למינוס** ב־$x_0$ אם קיים $\delta > 0$ כך ש:

$$f(x) > 0 \quad \forall x_0 - \delta < x < x_0$$
$$f(x) < 0 \quad \forall x_0 < x < x_0 + \delta$$

## שמירת סימן

נאמר כי $f$ **שומרת סימן** ב־$x_0$ אם היא לא מחליפה סימן, כלומר הסימן שלה זהה משני צידי $x_0$ (בסביבה מנוקבת מספיק קטנה).
