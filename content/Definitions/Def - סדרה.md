# הגדרה: סדרה

## הגדרה פורמלית

סדרה היא רשימה אינסופית מסודרת ובעלת איבר ראשון של מספרים ממשיים:

$$a_1, a_2, \ldots, a_n, \ldots$$

**סימונים:** נסמן סדרה בקיצור $(a_n)_{n=1}^{\infty}$ או $\{a_n\}_{n=1}^{\infty}$, או לעתים פשוט $(a_n)$.

## הסבר

אפשר לחשוב על סדרה כעל התאמה (פונקציה) שמתאימה לכל מספר טבעי $n$ את המספר הממשי $a_n$:

$$a: \mathbb{N} \to \mathbb{R}$$

ניתן לתאר סדרה בכמה דרכים:
- **באופן מפורש** - על ידי התלות של האיבר ה-$n$ במיקומו בסדרה (כלומר ב-$n$)
- **על ידי כלל נסיגה** - הגדרת איבר על ידי האיברים הקודמים לו

## דוגמאות

1. **[[Def - סדרה קבועה|סדרה קבועה]]:** $a_n = c$ לכל $n \in \mathbb{N}$

2. **[[Def - סדרה חשבונית|סדרה חשבונית]]:** $a_n = c + nd$ עבור $c, d \in \mathbb{R}$. ניתנת להצגה על ידי כלל הנסיגה $a_{n+1} = a_n + d$ ו-$a_0 = c$

3. **סדרת האי-זוגיים:** $\{2n - 1\}_{n=1}^{\infty} = 1, 3, 5, 7, \ldots$

4. **סדרת ריבועים:** $a_n = n^2$ נותנת $1, 4, 9, 16, \ldots$
