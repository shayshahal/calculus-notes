# הגדרה: פונקציה הפיכה

## הגדרה פורמלית

פונקציה $f : A \to B$ נקראת **הפיכה** אם קיימת פונקציה $g : B \to A$ המקיימת:

$$\forall a \in A \quad g \circ f(a) = a$$
$$\forall b \in B \quad f \circ g(b) = b$$

כלומר $f \circ g : B \to B$ ו-$g \circ f : A \to A$ הן פונקציות הזהות של $B$ ו-$A$ בהתאמה.

## הפונקציה ההופכית

הפונקציה $g$ נקראת **פונקציה הופכית** (הפוכה) ל-$f$. מסמנים אותה ב-$f^{-1}$.

## משפט: תנאי להפיכות

$f$ הפיכה אם"ם היא [[Def - פונקציה חח״ע|חח"ע]] ו[[Def - פונקציה על|על]].

בנוסף, אם קיימת ל-$f$ פונקציה הופכית היא יחידה.

## דוגמה

הפונקציה $f : \mathbb{R}^+ \to \mathbb{R}^+$ הנתונה ע"י $f(x) = x^2$ היא חח"ע ועל.

קיימת לה פונקציה הופכית יחידה:
$$f^{-1}(y) = \sqrt{y}$$

מתקיים:
$$f^{-1}(f(x)) = \sqrt{x^2} = x \quad \text{(לכל } x \geq 0\text{)}$$
$$f(f^{-1}(y)) = (\sqrt{y})^2 = y \quad \text{(לכל } y \geq 0\text{)}$$
