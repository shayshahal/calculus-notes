# מבחן הנגזרת הראשונה

שיטה למציאת נקודות קיצון מקומיות באמצעות הנגזרת הראשונה.

## תנאים

נניח $f$ רציפה בסביבה של $x_0$, גזירה בסביבה מנוקבת. נניח כי $x_0$ [[Def - נקודה קריטית|נקודה קריטית]].

## המבחן

1. אם $f'$ [[Def - החלפת סימן|מחליפה סימן ממינוס לפלוס]] ב־$x_0$ אז $x_0$ **מינימום מקומי** של $f$.
2. אם $f'$ מחליפה סימן מפלוס למינוס ב־$x_0$ אז $x_0$ **מקסימום מקומי** של $f$.
3. אם $f'$ שומרת סימן ב־$x_0$ אז $x_0$ **אינה נקודת קיצון**.

## הוכחה (עבור 1)

$f'$ מחליפה סימן ממינוס לפלוס, ולכן קיים $\delta > 0$ כך ש:

$$f'(x) < 0 \quad \forall x_0 - \delta < x < x_0$$
$$f'(x) > 0 \quad \forall x_0 < x < x_0 + \delta$$

נראה כי $x_0$ מינימום מקומי. יהי $x_0 < x < x_0 + \delta$.

$f$ רציפה ב־$[x_0, x]$, גזירה ב־$(x_0, x)$ ולכן לפי [[Thm - משפט לגרנז׳]] יש $x_0 < c_x < x$ המקיימת:

$$f(x) - f(x_0) = \underbrace{f'(c_x)}_{\text{חיובי, כי } x_0 < c_x < x < x_0+\delta} \cdot (x - x_0) > 0$$

ולכן $f(x) > f(x_0)$.

באופן דומה, נניח $x_0 - \delta < x < x_0$. שוב קיימת $x < c_x < x_0$ כך ש:

$$f(x_0) - f(x) = \underbrace{f'(c_x)}_{\text{שלילי, כי } x_0-\delta < x < c_x < x_0} \cdot (x_0 - c_x) < 0$$

ולכן $f(x) > f(x_0)$. בכל מקרה קיבלנו כי אם מתקיים $|x - x_0| < \delta$ אזי:

$$f(x) \geq f(x_0)$$

לכן $x_0$ מינימום מקומי.
