# משפט: צפיפות הרציונליים

## ניסוח

יהיו $x, y \in \mathbb{R}$ כך ש-$x < y$. אזי קיים $q \in \mathbb{Q}$ המקיים:
$$x < q < y$$

## הוכחה

נסמן $\epsilon = y - x > 0$.

לפי תכונת ארכימדס, קיים $n \in \mathbb{N}$ כך ש-$\frac{1}{n} < \epsilon$.

נסמן $m = [nx]$ (החלק השלם). הוא מקיים $m \leq nx < m + 1$.

נחלק ב-$n$ ונקבל:
$$\frac{m}{n} \leq x < \frac{m+1}{n}$$

כאשר $\frac{m+1}{n} \in \mathbb{Q}$.

נראה כי $\frac{m+1}{n} < y$:
$$y = (y - x) + x = \epsilon + x > \frac{1}{n} + x \geq \frac{1}{n} + \frac{m}{n} = \frac{m+1}{n}$$

ובסה"כ:
$$\frac{m+1}{n} \in \mathbb{Q}, \quad x < \frac{m+1}{n} < y$$

$\blacksquare$

## משמעות

המשפט אומר שהמספרים הרציונליים "צפופים" בתוך הממשיים - בין כל שני מספרים ממשיים שונים תמיד נמצא מספר רציונלי.
