# דוגמה: תתי-סדרות של סדרת מינוס אחד בחזקת n

## הסדרה

$$a_n = (-1)^n$$

זוהי הסדרה: $-1, 1, -1, 1, -1, 1, \ldots$

## תתי-סדרות

### תת-סדרה של מדדים זוגיים

עבור $n_k = 2k$:
$$a_{n_k} = a_{2k} = (-1)^{2k} = 1$$

זוהי הסדרה הקבועה $1, 1, 1, \ldots$

ולכן:
$$a_{2k} = 1 \xrightarrow{k \to \infty} 1$$

### תת-סדרה של מדדים אי-זוגיים

עבור $n_k = 2k + 1$:
$$a_{n_k} = a_{2k+1} = (-1)^{2k+1} = -1$$

זוהי הסדרה הקבועה $-1, -1, -1, \ldots$

ולכן:
$$a_{2k+1} = -1 \xrightarrow{k \to \infty} -1$$

## מסקנה

הסדרה $a_n = (-1)^n$ **מתבדרת**, כי יש לה שתי תתי-סדרות השואפות לגבולות שונים ($1$ ו-$-1$).

לפי [[Thm - שתי תתי-סדרות עם גבולות שונים גוררות התבדרות]], הסדרה לא מתכנסת במובן הרחב.
