# שיטה: הוכחת גבול מההגדרה

## מתי להשתמש

כאשר רוצים להוכיח באופן פורמלי ש-$\lim_{n \to \infty} a_n = L$ ישירות מ[[Def - גבול של סדרה|הגדרת הגבול]], במיוחד כאשר:
- לא ניתן להשתמש ב[[Thm - אריתמטיקת גבולות|אריתמטיקת גבולות]]
- רוצים להראות הבנה של ההגדרה
- יש צורך בהערכה מדויקת של קצב ההתכנסות

## השלבים

### שלב 1: פתיחה
כתוב: "יהי $\varepsilon > 0$."

### שלב 2: העריך את $|a_n - L|$
- פשט את הביטוי $|a_n - L|$
- מצא חסם עליון נוח לביטוי
- השתמש ב[[Thm - אי-שוויון המשולש|אי-שוויון המשולש]] לפי הצורך

### שלב 3: מצא את $N$
- פתור את האי-שוויון: (החסם העליון) $< \varepsilon$
- קבע $N$ כתלות ב-$\varepsilon$

### שלב 4: וודא
- בדוק שלכל $n \geq N$ אכן מתקיים $|a_n - L| < \varepsilon$
- סכם: "לכן על פי הגדרה, $a_n \to L$"

## דוגמה מפורטת

**הוכיחו כי** $\lim_{n \to \infty} \frac{n^2 + 1}{n^2 - 7n + 2} = 1$

**פתרון:**

**שלב 1:** יהי $\varepsilon > 0$. נרצה למצוא $N$ (התלוי ב-$\varepsilon$) עבורו לכל $n \geq N$ מתקיים:
$$\left| \frac{n^2 + 1}{n^2 - 7n + 2} - 1 \right| < \varepsilon$$

**שלב 2:** מכנה משותף בערך המוחלט:
$$\left| \frac{n^2 + 1}{n^2 - 7n + 2} - 1 \right| = \left| \frac{n^2 + 1 - n^2 + 7n - 2}{n^2 - 7n + 2} \right| = \left| \frac{7n - 1}{n^2 - 7n + 2} \right|$$

נרצה להיפטר מהערך המוחלט. המונה חיובי. במכנה:
$$n^2 - 7n + 2 \geq n^2 - 7n \geq n^2 - \frac{1}{2}n^2 = \frac{1}{2}n^2 \quad \text{כאשר } n \geq 14$$

לכן:
$$\left| \frac{7n - 1}{n^2 - 7n + 2} \right| \leq \frac{7n + 1}{\frac{1}{2}n^2} \leq \frac{1000n}{n^2} = \frac{1000}{n}$$

**שלב 3:** נרצה $\frac{1000}{n} < \varepsilon$, כלומר $n > \frac{1000}{\varepsilon}$.

נבחר $N$ כלשהו הגדול מ-$\frac{1000}{\varepsilon}$ וגם מ-$14$ (כדי שהחסם על המכנה יתקיים).

**שלב 4:** לכל $n \geq N$:
$$\left| \frac{n^2 + 1}{n^2 - 7n + 2} - 1 \right| \leq \frac{1000}{n} \leq \frac{1000}{N} < \varepsilon$$

לכן על פי הגדרה, $\frac{n^2 + 1}{n^2 - 7n + 2} \to 1$.

## טיפים

1. **אל תפחדו מקבועים גדולים** - הם לא משנים את קיום הגבול, רק את ה-$N$

2. **פשטו את המכנה** - לעתים קרובות $n^2 - 7n + 2 \approx \frac{1}{2}n^2$ מספיק טוב

3. **בדקו את הכיוון** - ודאו שאי-השוויונות הולכים בכיוון הנכון

4. **תנאי תחילה** - לפעמים צריך $n$ גדול מספיק כדי שחסמים מסוימים יתקיימו
