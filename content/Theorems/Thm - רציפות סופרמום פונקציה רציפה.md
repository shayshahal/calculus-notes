# משפט: רציפות סופרמום פונקציה רציפה

## ניסוח

נתונה פונקציה $f : [0,1] \to \mathbb{R}$ רציפה. נגדיר פונקציה חדשה באופן הבא:

$$M(t) = \sup\{f(x) \mid 0 \leq x \leq t\}$$

אזי $M(t)$ רציפה בקטע $[0,1]$.

## הוכחה

### שלב 1: $M(t)$ מוגדרת היטב

ראשית נשים לב שלפי [[Thm - משפט ויירשטראס]] התמונה $f([0,t])$ חסומה, לכן $M(t)$ מוגדרת היטב.

### שלב 2: $M(t)$ מונוטונית

נשים לב כי לכל $t' \leq t$ מתקיים כי $[0, t'] \subset [0, t]$ ולכן $M(t)$ פונקציה מונוטונית עולה.

לכן קיימים הגבולות החד-צדדיים ומספיק להראות כי:
$$\lim_{t \to t_0^-} M(t) = \lim_{t \to t_0^+} M(t) = M(t_0)$$

### שלב 3: רציפות מימין

תהי $t_0 \in (0,1)$ ויהי $\varepsilon > 0$.

לפי רציפות $f(x)$ מימין, קיים $\delta_1 > 0$ כך שאם $0 \leq x - t_0 \leq \delta_1$ אז $|f(x) - f(t_0)| < \varepsilon$.

כלומר:
$$\sup\{f(x) \mid t_0 \leq x \leq t_0 + \delta_1\} \leq f(t_0) + \varepsilon \leq M(t_0) + \varepsilon$$

**הסבר:** בקטע $[t_0, t_0 + \delta_1]$ הפונקציה רציפה ולכן מקבלת מקסימום, נניח בנקודה $x_1$, אבל מהרציפות של $f$ ומכך ש-$0 \leq x_1 - t_0 \leq \delta_1$:
$$\sup\{f(x) \mid t_0 \leq x \leq t_0 + \delta_1\} - f(t_0) = f(x_1) - f(t_0) < \varepsilon$$

קיבלנו שאם $t \in [t_0, t_0 + \delta)$ אז:
$$M(t) = \sup\{f(x) \mid 0 \leq x \leq t\}$$
$$= \max\{\sup\{f(x) \mid 0 \leq x \leq t_0\}, \sup\{f(x) \mid t_0 \leq x \leq t\}\}$$
$$\leq \max\{M(t_0), M(t_0) + \varepsilon\} = M(t_0) + \varepsilon$$

לכן:
$$M(t) - M(t_0) \stackrel{\text{Mon.}}{=} |M(t) - M(t_0)| \leq \varepsilon$$

כלומר לכל $\varepsilon > 0$ מצאנו $\delta_1 > 0$ כך ש:
$$t \in [t_0, t_0 + \delta) \implies |M(t) - M(t_0)| \leq \varepsilon$$

ולכן $M(t)$ רציפה מימין ב-$t_0$.

### שלב 4: רציפות משמאל

נראה רציפות משמאל ב-$t_0$: לפי רציפות $f(x)$ משמאל, קיים $\delta_2 > 0$ כך שאם $0 \leq t_0 - x < \delta_2$ אז $|f(x) - f(t_0)| < \varepsilon/2$.

לכן כאשר $t \in (t_0 - \delta_2, t_0]$ יש שתי אפשרויות:

1. אם הערך המקסימלי של $f(x)$ מתקבל כאשר $x \leq t_0 - \delta_2$ אזי $M(t) = M(t_0)$ והפונקציה רציפה משמאל כי היא קבועה.

2. אחרת, הערך המקסימלי של $f$ בקטע $[0, t_0]$ מתקבל בקטע $(t_0 - \delta_2, t_0]$. מכיוון ש-$f$ רציפה על הקטע $[0, t_0]$ אז המקסימום שלה מתקבל באיזו נקודה $x_2 \in (t_0 - \delta_2, t_0]$ ולכן:
$$M(t_0) = \sup\{f(x) \mid t_0 - \delta_2 \leq x \leq t_0\}$$
$$= f(x_2) = f(x_2) - f(t_0) + f(t_0) - f(t) + f(t)$$
$$\leq |f(x_2) - f(t_0)| + |f(t_0) - f(t)| + f(t)$$
$$\leq \varepsilon/2 + \varepsilon/2 + f(t) = f(t) + \varepsilon \leq M(t) + \varepsilon$$

לכן לכל $t \in (t_0 - \delta_2, t_0]$:
$$M(t_0) \leq M(t) + \varepsilon$$

כלומר:
$$|M(t_0) - M(t)| \stackrel{\text{Mon.}}{=} M(t_0) - M(t) \leq \varepsilon$$

ולכן $M(t)$ רציפה משמאל ב-$t_0$.

### סיכום

סה"כ קיבלנו ש-$M(t)$ רציפה ב-$t_0$ עבור $t_0 \in (0,1)$ כללי, ומאותו טיעון חד-צדדי ניתן לראות שהיא גם רציפה מימין ומשמאל בנקודות הקצה, אז היא רציפה ב-$[0,1]$ כרצוי.
