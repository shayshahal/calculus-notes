# משפט: קריטריון לאי-רציפות במידה שווה

## ניסוח

פונקציה $f$ **אינה רציפה במידה שווה** ב-$A$ אם ורק אם:

$$\exists \varepsilon > 0 \text{ וסדרות } x_n, y_n \in A \text{ כך ש-} |x_n - y_n| \to 0 \text{ אבל } |f(x_n) - f(y_n)| \geq \varepsilon$$

## הסבר

זהו כלי נוח להוכיח שפונקציה **לא** רציפה במידה שווה:

1. מוצאים $\varepsilon > 0$ קבוע
2. בונים שתי סדרות $x_n, y_n$ שמתקרבות זו לזו (ההפרש ביניהן שואף לאפס)
3. מראים שערכי הפונקציה בנקודות אלו נשארים רחוקים לפחות ב-$\varepsilon$

## דוגמה

נראה ש-$f(x) = e^x$ לא רציפה במ"ש ב-$(0, \infty)$:

נגדיר $x_n = \log n$ ו-$y_n = \log(n+1)$.

אז:
$$|y_n - x_n| = \log\left(1 + \frac{1}{n}\right) \xrightarrow{n\to\infty} 0$$

אבל:
$$|f(y_n) - f(x_n)| = |e^{\log(n+1)} - e^{\log n}| = |n+1 - n| = 1$$

לכן עבור $\varepsilon = 1$ מצאנו סדרות שמקיימות את התנאי.
