# משפט: התבדרות טור ההופכיים של הראשוניים

## ניסוח

תהי $\mathbb{P} = \{p_1, p_2, p_3, \ldots\}$ קבוצת המספרים הראשוניים, בסדר עולה.

הטור $\displaystyle\sum_{i \geq 1} \frac{1}{p_i}$ מתבדר.

## הוכחה

נניח בשלילה כי הטור $\sum_{i \geq 1} \frac{1}{p_i}$ מתכנס.

אזי משום שטור הזנבות שואף לאפס, קיים $k \in \mathbb{N}$ כך שלכל $K > k$ מתקיים:
$$\sum_{i \geq k+1} \frac{1}{p_i} < \frac{1}{2}$$

לראשוניים $p_1, \ldots, p_k$ נקרא **קטנים** ולראשוניים $p_{k+1}, p_{k+2}, \ldots$ נקרא **גדולים**.

יהי $N \in \mathbb{N}$. נסמן:
- $N_b$ = מספר ה-$n \leq N$ להם לפחות מחלק ראשוני גדול אחד
- $N_s$ = מספר ה-$n \leq N$ להם מחלקים ראשוניים קטנים בלבד

מהגדרה: $N_s + N_b = N$.

**הערכת $N_b$:**

לכל $i \geq k+1$, מספר ה-$n \leq N$ כך ש-$p_i | n$ הוא $\left\lfloor \frac{N}{p_i} \right\rfloor \leq \frac{N}{p_i}$.

לכן:
$$N_b \leq \sum_{i \geq k+1} \frac{N}{p_i} < \frac{N}{2}$$

**הערכת $N_s$:**

כל $n \in \{n \leq N : \forall i \geq k+1, p_i \nmid n\}$ ניתן לרשום כ-$n = a_n b_n^2$ כאשר $a_n$ חופשי מריבועים (מכפלה של ראשוניים שונים).

$a_n$ הוא מכפלה של $p_1, \ldots, p_k$ ולכן קיימות $2^k$ אפשרויות עבורם.

כמו כן $b_n^2 \leq N$ ולכן $b_n \leq \sqrt{N}$.

לכן:
$$N_s \leq 2^k \sqrt{N}$$

**סתירה:**

כאשר נבחר $N = 2^{2k+2}$ נקבל:
$$N_s + N_b < 2^k \sqrt{N} + \frac{N}{2} = 2^{2k+1} + 2^{2k+1} = 2^{2k+2} = N$$

אך $N_b + N_s = N$ וזו סתירה. $\square$

## מסקנה

ישנם אינסוף ראשוניים.
