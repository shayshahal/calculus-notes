# משפט: משוואה פונקציונלית קושי

## ניסוח

מצאו את כל הפונקציות הרציפות $f : \mathbb{R} \to \mathbb{R}$ המקיימות את המשוואה:
$$f(x + y) = f(x) + f(y), \quad \forall x, y \in \mathbb{R}$$

**תשובה:** כל הפתרונות הרציפים הם מהצורה $f(x) = ax$ עבור קבוע $a \in \mathbb{R}$.

## הוכחה

### שלב 1: הפתרון מהצורה $ax$ מקיים

נשים לב שכל פונקציה מהצורה $f(x) = ax$ מקיימת את המשוואה:
$$f(x+y) = a(x+y) = ax + ay = f(x) + f(y)$$

### שלב 2: $f(0) = 0$

מהנתון $f(2x) = 2f(x)$ לכל $x \in \mathbb{R}$.

ובפרט $f(0) = f(0+0) = f(0) + f(0) = 2f(0)$, ולכן $f(0) = 0$.

### שלב 3: לינאריות על הטבעיים

באינדוקציה מוכיחים כי לכל $n \in \mathbb{N}$: $f(nx) = nf(x)$.

נציב $x = \frac{y}{n}$ ולכן $\frac{1}{n}f(y) = f\left(\frac{y}{n}\right)$.

### שלב 4: לינאריות על הרציונליים

אם $r = \frac{p}{q} \in \mathbb{Q}_+$ אזי:
$$f(rx) = f\left(\frac{p}{q}x\right) = pf\left(\frac{x}{q}\right) = \frac{p}{q}f(x) = rf(x)$$

### שלב 5: הפונקציה אי-זוגית

נשים לב בנוסף כי:
$$0 = f(0) = f(x + (-x)) = f(x) + f(-x) \Rightarrow f(x) = -f(-x)$$

לכן $f(-rx) = -f(rx) = -rf(x)$, כלומר קיבלנו כי $f(qx) = qf(x)$ לכל $q \in \mathbb{Q}$.

### שלב 6: הרחבה לממשיים

תהי $\alpha$ מספר ממשי. לכל $\alpha$ קיימת סדרה $\{r_n\}$ של מספרים רציונליים כך ש-$r_n \to \alpha$.

לפי רציפות $f$ מקבלים:
$$f(\alpha x) = f\left(\lim_{n \to \infty} r_n x\right) = \lim_{n \to \infty} f(r_n x) = \lim_{n \to \infty} r_n f(x) = \alpha f(x)$$

### סיכום

אם נציב $x = 1$, נקבל כי $f(\alpha) = \alpha f(1)$, ולכן $f(x) = ax$ לכל $x \in \mathbb{R}$ כאשר $a = f(1)$.

## הערות

- ללא דרישת הרציפות, קיימים פתרונות "פתולוגיים" רבים (דורשים אקסיומת הבחירה)
- משוואה זו נקראת משוואת קושי הפונקציונלית
