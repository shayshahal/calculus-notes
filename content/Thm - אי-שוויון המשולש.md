# משפט: אי-שוויון המשולש

## ניסוח

לכל $x, y \in \mathbb{R}$ מתקיים:

$$||x| - |y|| \leq |x + y| \leq |x| + |y|$$

## הוכחה (האי-שוויון הימני)

יהיו $x, y \in \mathbb{R}$.

מתקיים $-|x| \leq x \leq |x|$ ו-$-|y| \leq y \leq |y|$.

נסכום את אי-השוויונות ונקבל:

$$-(|x| + |y|) \leq x + y \leq |x| + |y|$$

כלומר $|x + y| \leq |x| + |y|$.

## הערה

הכיוון השני (האי-שוויון השמאלי) נשאר כתרגיל בית.
