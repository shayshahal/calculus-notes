# דוגמה: נגזרת של $f(x) = x|x|$

## הגדרת הפונקציה

$$f(x) = x|x| = \begin{cases} x^2 & x \geq 0 \\ -x^2 & x < 0 \end{cases}$$

## חישוב הנגזרת

**עבור $x > 0$:** $f(x) = x^2$, לכן $f'(x) = 2x$.

**עבור $x < 0$:** $f(x) = -x^2$, לכן $f'(x) = -2x$.

**בנקודה $x = 0$:** נחשב נגזרות חד-צדדיות.

$$f'_+(0) = \lim_{h \to 0^+} \frac{h^2 - 0}{h} = \lim_{h \to 0^+} h = 0$$

$$f'_-(0) = \lim_{h \to 0^-} \frac{-h^2 - 0}{h} = \lim_{h \to 0^-} (-h) = 0$$

הנגזרות החד-צדדיות שוות, לכן $f'(0) = 0$.

## מסקנה

$$f'(x) = \begin{cases} 2x & x > 0 \\ 0 & x = 0 \\ -2x & x < 0 \end{cases} = 2|x|$$

או בקיצור: $f'(x) = 2|x|$.

## הערה

זו דוגמה לפונקציה שגזירה בכל $\mathbb{R}$ למרות שהיא מוגדרת בחתיכות.
