# דוגמה: רציפות פונקציה עם רצפה

## הפונקציה

$$f(x) = \lfloor x \rfloor + (x - \lfloor x \rfloor)^{\lfloor x \rfloor}, \quad x \geq \frac{1}{2}$$

מיינו נקודות אי-רציפות (אם ישנן).

## פתרון

### ניתוח הפונקציה

אפשר לתת דוגמאות לקטעים $\left(\frac{1}{2}, 1\right), (1, 2)$ וכו'.

נשים לב כי לכל $n \geq 0$, עבור $x \in [n, n+1)$ מתקיים $\lfloor x \rfloor = x - n$ ולכן:
$$f(x) = n + (x - n)^n$$

### בדיקת רציפות בנקודות פנימיות

בקטע $(n, n+1)$ מתקיים $x - n > 0$ ולכן הפונקציה $f$ מוגדרת אלמנטרית ולכן רציפה ב-$(n, n+1)$.

### בדיקת רציפות בנקודות שלמות

כמוכן מחשבון גבולות, עבור $n \geq 1$ מתקיים:

**גבול מימין:**
$$\lim_{x \to n^+} f(x) = n + \lim_{x \to n}(x-n)^n = n + 0 = n = f(n)$$

**גבול משמאל:** עבור $n \geq 0$:
$$\lim_{x \to (n+1)^-} f(x) = n + (x-n)^n = n + 1^n = n + 1 = f(n+1)$$

### מסקנה

הראינו רציפות מימין ומשמאל בכל $x \geq 1$ שלם, וכן רציפות בכל $x \geq \frac{1}{2}$ לא שלם.

לכן **הפונקציה $f$ רציפה בקטע** $\left[\frac{1}{2}, \infty\right)$.

## הסבר

- למרות שהפונקציה מוגדרת באמצעות פונקציית הרצפה (שאינה רציפה), הצירוף של כל החלקים יוצר פונקציה רציפה
- הסיבה היא שבנקודות השלמות הגבולות החד-צדדיים שווים לערך הפונקציה
