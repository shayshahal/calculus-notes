# דוגמה: sin(1/x) ותכונת ערך הביניים

## הגדרה

נגדיר:
$$f(x) = \begin{cases} \sin\left(\frac{1}{x}\right) & x > 0 \\ 0 & x = 0 \end{cases}$$

הראו כי $f$ **לא רציפה** בקטע $[0,1]$ אבל **מקיימת את תכונת ערך הביניים** (תמונה של קטע היא קטע).

## פתרון

### $f$ לא רציפה ב-$0$

אפשר לקחת סדרות $x_n = \frac{1}{2\pi n} \to 0$ ו-$y_n = \frac{1}{2\pi n + \frac{\pi}{2}} \to 0$ אבל:
- $f(x_n) = \sin(2\pi n) = 0$
- $f(y_n) = \sin\left(2\pi n + \frac{\pi}{2}\right) = 1$

לכן אין גבול ב-$0$ ולבטח אין רציפות.

### $f$ מקיימת תכונת ערך הביניים

מצד שני, נראה כי לכל $t_1 < t_2$ התמונה $f([t_1, t_2])$ היא קטע.

**מקרה $t_1 > 0$:** אם $t_1 > 0$ זה ברור כי $f$ רציפה על $[t_1, t_2]$ (כהרכבה של פונקציות רציפות).

**מקרה $t_1 = 0$:** נראה כי התמונה של הקטע $[0, t_2]$ היא הקטע $[-1, 1]$.

עבור $n$ מספיק גדול מתקיים כי:
$$0 < \frac{1}{2\pi n + \frac{\pi}{2}} < \frac{1}{2\pi n - \frac{\pi}{2}} < t_2$$

אבל:
$$f\left(\frac{1}{2\pi n + \frac{\pi}{2}}\right) = \sin\left(2\pi n + \frac{\pi}{2}\right) = 1$$
$$f\left(\frac{1}{2\pi n - \frac{\pi}{2}}\right) = \sin\left(2\pi n - \frac{\pi}{2}\right) = -1$$

ולכן התמונה של הקטע $\left[\frac{1}{2\pi n + \frac{\pi}{2}}, \frac{1}{2\pi n - \frac{\pi}{2}}\right]$ היא הקטע $[-1, 1]$ (כי $f$ רציפה שם).

כלומר בפרט התמונה של $[0, t_2]$ היא גם כן $[-1, 1]$.

## מסקנה

**תכונת ערך הביניים לא גוררת רציפות.**

## הסבר

- המשפט אומר שאם פונקציה רציפה, אז יש לה תכונת ערך הביניים
- הדוגמה מראה שההפך לא נכון: יכולה להיות פונקציה עם תכונת ערך הביניים שאינה רציפה
- עם זאת, אם הפונקציה גם **מונוטונית** וגם מקיימת תכונת ערך הביניים, אזי היא רציפה
